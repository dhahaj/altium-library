Enable new tables in Altium

Altium only shows tables that are listed and enabled in your .DbLib. Upload your current file to see which of your tables are missing, then download a patched copy with them added.

The file is read in memory and never stored or logged. It holds your reader password.

{% include "_dblib_status.html" %}

After downloading

  1. Keep a backup of your current Daniel.DbLib.
  2. Close Altium, or uninstall the library first (Components panel ▸ ≡ ▸ File-based Libraries Preferences).
  3. Save the downloaded file over Daniel.DbLib.
  4. Open Altium again (reinstall the library if you removed it) and refresh the Components panel.

Only new [TableN] and [FieldMapN] sections are appended at the end; everything already in the file stays byte-for-byte the same. Field mappings follow Celestial's own tables: Part Number is the lookup key, Comment and Value are visible on placement, and the rest become parameters with the column's name.
